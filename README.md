# Master

A single-player 4X strategy game in the spirit of *Master of Magic* and the
original *Master of Orion*, with pixel graphics. Five schools of magic, eight
planes, thirty races, auto-resolved tactical battles you watch and learn from.

- **Design:** [docs/DESIGN.md](docs/DESIGN.md)
- **Architecture:** [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)

## Quick start

```sh
npm install
npm run dev      # dev server
npm test -- --run  # test suite
npm run build    # typecheck + production build
```
